# hunterdr

Juego de caza en navegador con Phaser, TypeScript y Vite.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Despliegue en Netlify

```bash
npm run build
netlify deploy --prod
```

La configuración de Netlify está en `netlify.toml` y publica la carpeta `dist`.
