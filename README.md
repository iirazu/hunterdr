# hunterdr

Juego de caza 2D vertical para navegador, construido con Phaser, TypeScript y Vite.

## Requisitos

- Node.js 18 o superior
- npm

## Desarrollo

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

La salida se genera en `dist/`.

## Despliegue en Netlify

El archivo `netlify.toml` ya está configurado para compilar con Vite y publicar `dist`.

## Estructura

```text
src/
  main.ts
  scenes/
  entities/
  systems/
  data/
```
